# Employee-Stress-Analysis-using-Tableau
## Overview
Data analysis project exploring the relationship between screen time and employee stress 

## Tools Used
- Microsoft Excel
- Tableau
- Kaggle

## Features
- Interactive Tableau dashboard visualizing stress patterns across demographics
- Analysis of 5,000 employee records from Kaggle
- Key findings:
  - Employees with 4+ hours of social media use had 78% higher anxiety scores
  - Work-related screen time above 4 hours correlated with 60% higher depression scores
  - Urban employees reported the highest average stress levels
- Business recommendations for reducing digital burnout

## What I Learned
- Data cleaning and preparation in Excel
- Building interactive dashboards in Tableau
- Translating data insights into business recommendations
- Applying statistical analysis to real-world datasets
